# Distance Calculator

## Description

This program calculates the distance between two points using the distance formula. The user enters the x- and y-coordinates of two points, and the program calculates and displays the distance rounded to two decimal places.

## How to Run

1. Open the Python program.
2. Run the program.
3. Enter the x-coordinate and y-coordinate of the first point.
4. Enter the x-coordinate and y-coordinate of the second point.
5. The program will display the distance between the two points.

## Input Needed

* x-coordinate of the first point
* y-coordinate of the first point
* x-coordinate of the second point
* y-coordinate of the second point

## Sample Output

```text
Enter x1: 2
Enter y1: 3
Enter x2: 7
Enter y2: 8
The distance between the two points is: 7.07
```
